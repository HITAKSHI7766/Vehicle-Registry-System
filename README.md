# Vehicle Registry System

## About the Project
This is a simple C++ project used to manage different types of vehicles. It demonstrates Object-Oriented Programming concepts.

## Features
- Add different types of vehicles
- Display all vehicles
- Search vehicle by ID
- Menu-driven program

## Inheritance
- Single Inheritance
- Multilevel Inheritance
- Multiple Inheritance
- Hierarchical Inheritance

## Technologies Used
- C++
- Object-Oriented Programming

## How to Run
Compile the program:

```bash
g++ VehicleRegistrySystem.cpp -o main
```

Run the program:

```powershell
.\main.exe
```
